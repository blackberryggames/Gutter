# Gutter

Desktop editor for manhwa / manga narration videos (Windows).

**Download:** [GutterSetup.exe](releases/v1.08/GutterSetup.exe) (installer, recommended) or [Gutter.exe](releases/v1.08/Gutter.exe) (portable)

This repo hosts Gutter's releases. The app checks `version.json` when it starts and offers new versions automatically.
See [CHANGELOG.md](CHANGELOG.md) for what changed.

Write scripts with your Claude app (no API key): [Gutter Script Generator MCP](https://github.com/blackberryggames/Gutter-Script-Generator-MCP).
